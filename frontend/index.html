Design Guide

Every page is built from these tokens and components. Values below are read live from the stylesheet.
Shell
Same on every page

One header height, one rail width, one page padding and one content width. The rail is icons only; the menu button opens it over the content with a scrim and it closes after you navigate. Every page reserves room under the talk bar, so nothing sits beneath it.

Fluid · clamp()

Eight sizes, each a clamp() against the viewport width, so text grows smoothly from a phone to a large monitor. Geist carries everything; Bricolage Grotesque appears only on display numerals.

Rules
Cyan means signal
#A7EBF2 marks live data, the active item and focus. It is never decoration.
No page-specific styling
A page is a page head plus cards, rows, controls and buttons from this guide. New needs become new components here first.
Nothing under the talk bar
Pages pad their bottom by --dock-clear: the bar's height, its gap to the edge and a margin.
Motion is physical and brief
Presses scale to 0.97 in 120ms; hover only on real pointers; prefers-reduced-motion turns movement off.
